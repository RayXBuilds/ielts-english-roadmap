本次选择十二课由 VOA 制作的日常英语情景教学内容，课程页均署名 VOA，下载前检查页面，未见这十二课材料标注第三方通讯社供稿；不包含新闻、图片库或用户评论。保留视频原有标识，不声称得到 VOA 或 IELTS 背书。新增素材必须单独核对来源，不能因托管在 VOA 域名就直接复制。
