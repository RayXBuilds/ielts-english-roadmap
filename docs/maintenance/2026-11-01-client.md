# 2026-11-01 客户端开发与验证记录

新增本地 Swift AppKit/WKWebView 应用、离线学习界面、课程生成脚本、原生构建与打包脚本、状态恢复测试和使用说明。复用 50 个学习条目、84 天日程及 24 个已授权媒体，没有新第三方下载。手写程序采用 MIT，原创课程仍为 CC BY 4.0，VOA 媒体保留原署名与来源清单。

实际验证：

- Mac 应用编译、启动、课程目录和阅读界面显示正常。
- R01 标记完成并写入笔记，退出重启后完成计数保留；导出的 JSON 保留该笔记。
- L01 本地 MP3 播放计时推进至 23 秒；本地 MP4 播放计时推进，截图核对到 VOA 课程画面。本次是抽样实播，不声称完整观看全部视频或完成多系统兼容测试。
- 生词添加和修改例句后，导出 JSON 与界面内容一致；系统保存面板实际写出备份。通过恢复文件面板导入空白备份，恢复后计数归零、本机进度文件为空白初始状态，测试记录不留在使用者进度中。
- 4 个 Node 状态测试通过：多语言数据往返、坏备份不替换记录、无效课程/时间/天数过滤、读取异常暂停写入且有效恢复后可继续。
- build_offline.py 同步生成网页与客户端数据，校验 84 天编号连续、课程 ID 唯一、计划链接有效。
- check_and_package.py 在临时目录通过原有链接、两种离线入口、媒体 SHA-256 与 ZIP 完整性检查；没有改写 v0.4 历史发布文件。
- Mac 构建检查打包后的 24 个媒体哈希，codesign --verify --deep --strict 通过，ZIP CRC 检查通过，包内不含 progress.json；另附 SHA256SUMS-client.txt。
