# 阶段评估与学习记录

每周复盘一次，第 4、8、12 周做阶段评估。尽量选同来源、同等级、相近篇幅的新材料，比较才有意义。用旧文检验保留情况，用新文检验迁移能力，两者分开记录。

| 指标 | 怎样记录 | 怎么解释 |
|---|---|---|
| 持续性 | 实际学习次数和分钟数 | 先看是否能持续，不追求连续打卡 |
| 阅读 | 首次答对数/总题数、用时、查词次数 | 准确率稳定时查词减少，才值得尝试加难度 |
| 听力 | 首听主题和细节；核对文本后补全内容 | 区分词汇障碍与声音识别障碍 |
| 表达 | 录音长度、能否说清主题和两个细节 | 记“能否完成任务”，不要只数说了多久 |
| 互动 | 能否回答追问、主动提问、请求澄清 | 独自朗读流畅不等于能进行对话 |
| 词汇 | 隔一周能否用自己的句子表达 | 认识释义与主动使用分开记录 |

## 30 分钟周复盘

10 分钟重读一篇旧文并复述，10 分钟回听旧录音或完成一个短听力任务，5 分钟回顾本周表达，5 分钟决定下周只调整一项：难度、篇幅、频率或时间。

## 阶段检查

第 4 周检查：是否能每周学习至少四次、读完所选短文并说明主题、说三句自己的话。第 8 周检查：是否能对熟悉主题说一分钟并回答一个追问。第 12 周检查：是否能就熟悉主题进行几分钟交流，并在不懂时主动澄清。以上是练习目标，不是等级认证。

连续两周过于吃力时先减少篇幅或降一级；连续三篇新材料轻松完成再提高难度。若投入稳定而某项一直不进步，收集两个具体例子，请同伴或老师分析障碍。
