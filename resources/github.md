# GitHub 英语学习资料与工具

GitHub 的价值在于可复用的方法、工具与词汇索引。日常训练仍以有语境的文章和音频为主。下面的“如何使用”是本项目的建议；仓库功能与在线服务状态以原项目为准。

| 项目 | 主要用途 | 在本路线中的位置 | 注意事项 |
|---|---|---|---|
| [everyone-can-use-english](https://github.com/ZuodaoTech/everyone-can-use-english) | 《人人都能用英语》及相关学习项目 | 第一个周末选读词典、精读等相关章节，拿一个建议实践一周 | 方法阅读不要占满日常英语训练；关联服务的收费与账户要求另查 |
| [qwerty-learner](https://github.com/RealKai42/qwerty-learner) | 打字结合单词练习、发音和默写 | 需要巩固拼写时每次 3～5 分钟 | 打字速度不能代替阅读理解或口语能力；优先从仓库指向的入口使用 |
| [Anki](https://github.com/ankitects/anki) | 间隔复习工具 | 有复习需求后，保存每天三个表达与自造例句 | GitHub 是桌面端源码；下载请从项目官网进入，各端费用不同 |
| [most-frequent-technology-english-words](https://github.com/Wei-Xia/most-frequent-technology-english-words) | 技术英语词汇索引 | 工作与技术分支按实际阅读中遇到的词查询 | 不要求普通学习者背完技术词表 |
| [earthworm](https://github.com/cuixueshe/earthworm) | 通过句子构建练习英语 | 想加强句子表达时作为可选练习 | 在线服务与源码部署是不同使用方式，不要求自建环境 |

## 最小工具组合

第一周只用浏览器、纸笔和手机录音即可。第二周确有需要时，在 Anki 与 qwerty-learner 中选一个补充。不会 Git 的读者可以直接点击材料页学习，不必 clone、安装依赖或运行任何代码。

## 选择资源的规则

先看原项目 README 的用途，再检查学习内容是否合适、有没有文本和反馈、是否需要账号或额外费用。Star 数不等于教学效果，不凭热度替学习者决定难度。
