# 雅思英语学习路线：从阅读、听力到日常交流

**IELTS English Roadmap** · 雅思基础准备 · 成人英语重学 · 离线阅读 · 听力训练 · 英语口语

面向中文学习者的 12 周路线：恢复英文阅读习惯，逐步听懂、开口表达，再按需要衔接雅思。默认每天 30 分钟，每周五天学习、一天复盘、一天休息。12 周约 36 小时，是建立习惯与观察进步的周期，不承诺达到特定等级或雅思分数。

## 先下载再开始

**前 28 天的必修材料已全部放入仓库：12 篇原创短文、4 段官方对话 MP3、4 个官方课程 MP4，以及对话全文、练习和答案。** 获取后可以离线使用，不需要每天打开海外学习网站。

- [整包下载与离线使用说明](resources/offline-guide.md)：解压后双击 `offline.html`，即可阅读并播放音视频。
- [发布下载页](https://github.com/RayXBuilds/ielts-english-roadmap/releases)：完整包，以及体积更小的文字与音频包。
- [前 28 天任务表](plans/first-28-days.md)：从 Day 1 开始，不需要等到周一。
- [仓库内材料目录](resources/materials.md)：按编号直接读文章、听音频、看视频。

GitHub 本身的国内连接仍可能不稳定；整包下载后，离线学习入口不使用外部脚本、字体或播放器。HTML 在 GitHub 上显示为源码，请下载解压后打开。

## 今天怎样学

1. 做 [起点诊断](docs/01-start-here.md)，记录当前阅读与听力表现。
2. 读 [R01 A Small Daily Habit](lessons/readings/r01.md)，先不查词，回答三道题。
3. 听 [L01 Welcome!](lessons/listening/l01.md)，先听 MP3，再核对对话文本。
4. 说三句自我介绍，保存到自己的笔记或录音里。

初期阅读 20 分钟、听力 5 分钟、表达 5 分钟。视频与文章可以分多天反复使用，不必每天换新。

## 适用范围

适合学过英语但生疏、希望恢复实用能力，以及需要为雅思打基础的人。前四周材料较简单，用来找回习惯；已经轻松掌握者可从 R09～R12 或雅思衔接章节开始。原创短文难度是编辑建议，未经过正式 CEFR 校准。

第 5～12 周有路线与初步阅读素材，但本地音视频目前只有前四课，不等于完整 12 周课程库。后续需按进步选择新材料；外部资源列在可选拓展页。
