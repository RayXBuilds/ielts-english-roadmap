# 雅思英语学习路线：从阅读、听力到日常交流

**IELTS English Roadmap** · 雅思基础准备 · 成人英语重学 · 离线阅读 · 听力训练 · 英语口语

本项目现含两条路线：已有大学英语基础、准备雅思者优先使用 [U04：24 周备考主线](lessons/bridge/u04-exam-preparation.md)，每周 12 小时，含材料配额、反馈与阶段模考；[U05](lessons/bridge/u05-repair-library.md) 提供首轮长篇阅读与输出训练。完整外部试卷需自行合法取得，尚未全部内置。

基础恢复路线：恢复英文阅读习惯，逐步听懂、开口表达，再按需要衔接雅思。默认每天 30 分钟，每周五天学习、一天复盘、一天休息。12 周约 36 小时，是建立习惯与观察进步的周期，不承诺达到特定等级或雅思分数。

## 今天怎样学

已有大学英语基础且以考试为目标：先打开 **U04**，登记目标并做 T01 基线；U05 可立即离线练习。以下四步适用于基础恢复路线。

1. 做 [起点诊断](docs/01-start-here.md)，记录当前阅读与听力表现。
2. 读 [R01 A Small Daily Habit](lessons/readings/r01.md)，先不查词，回答三道题。
3. 听 [L01 Welcome!](lessons/listening/l01.md)，先听 MP3，再核对对话文本。
4. 说三句自我介绍，保存到自己的笔记或录音里。

初期阅读 20 分钟、听力 5 分钟、表达 5 分钟。视频与文章可以分多天反复使用，不必每天换新。

## 适用范围

适合学过英语但生疏、希望恢复实用能力，以及需要为雅思打基础的人。前四周材料较简单，用来找回习惯；已经轻松掌握者可从 R09～R12 及 R13～R24 或雅思衔接章节开始。原创短文难度是编辑建议，未经过正式 CEFR 校准。

第 5～12 周现已补齐逐日任务和本地材料。后半程逐渐增加复述、角色对话、临时追问与陌生材料检查。完成基础路线后，可继续扩展难度或进入雅思专项训练。
