# 雅思英语学习路线：从阅读、听力到日常交流

**IELTS English Roadmap** · 雅思基础准备 · 成人英语重学 · 分级阅读 · 听力训练 · 英语口语

一份面向中文学习者的英语自学路线：先能读懂短文章，再逐步听懂内容、表达自己的想法，最后按需要衔接雅思。适合学过英语、工作后生疏，以及希望为雅思打基础的人。零基础可从 A1 分支开始；近期必须参加考试的人应优先看雅思衔接章节。

默认每天 30 分钟，每周 5 天学习、1 天复盘、1 天休息，共 12 周。每周约 3 小时，12 周约 36 小时，这是建立习惯与观察进步的周期，不承诺达到特定等级或雅思分数。

## 今天从这里开始

1. 用 [起点诊断](docs/01-start-here.md) 选适合自己的材料难度。
2. 打开 [前 28 天任务表](plans/first-28-days.md)，从 Day 1 开始，不需要等到周一。
3. 阅读 [Study skills tips](https://learnenglish.britishcouncil.org/free-resources/reading/a2/study-skills-tips)，先独立理解，再查影响大意的词。
4. 用 [每日记录模板](templates/daily-log.md) 留下三句话与三个表达；个人记录保存在自己的私有空间。

初期日程：阅读 20 分钟，听力 5 分钟，表达 5 分钟。文章、音频与视频不必每天换新，同一材料分两三天练习。

## 三条可选路线

- **恢复基础**：先从 A1/A2 短文、短对话开始，跟随 28 天任务表。A1/A2/B1 是材料的 CEFR 等级标签，不是根据学历推定的个人水平。
- **实用英语**：基础稳定后加入科普、故事、工作资料，增加复述与真实对话。
- **雅思准备**：明确考试类型、分数与期限后，加入官方样题、限时练习、写作和口语反馈。

主线选用 British Council、VOA 等公开学习页面，补充 ELLLO、分级新闻及 GitHub 开源工具。只需同时使用一个阅读来源和一个听力来源，工具按需选一个。
