# 前 28 天离线学习任务

所有必修篇目、对话音频和课程视频均在仓库内。先按 [离线指南](../resources/offline-guide.md) 下载，或在 GitHub 点击下表的本地材料。R 为短文，L 为对话 MP3，V 为同课完整 MP4。每周学习五天、复盘一天、休息一天。

每课里的参考答案请在独立作答后展开；首次成绩与重做成绩分开记录。R08 留到 Day 24，作为未读材料检查。
