# 拾阶英语：雅思英语离线学习客户端

macOS 桌面客户端，面向中文自学者。从阅读、听力和日常交流开始，为雅思打基础。无需登录，课程与音视频随应用一起下载，学习时没有外部网站、字体、接口或播放器依赖。

## 下载与使用

在 [客户端发布页](https://github.com/RayXBuilds/ielts-english-roadmap/releases/tag/client-v0.2.10) 下载 `Stepwise-English-macOS-arm64-v0.2.10.zip`，解压得到「拾阶英语.app」，可将它放入「应用程序」文件夹后打开。不要直接在压缩包中运行。

- 首版为 Apple 芯片 Mac（M 系列、arm64），构建最低目标为 macOS 14；实测环境为当前开发 Mac。尚未逐一验证所有系统版本，未提供 Intel Mac 或 Windows 安装包。
- 当前为开发者预览版，使用本地 ad-hoc 签名，**没有 Apple Developer ID 签名或公证**。网上下载后可能被 macOS 拦截；此版本不承诺双击即能通过 Gatekeeper。仅在确认来源可信后，可按 [Apple 官方说明](https://support.apple.com/zh-cn/102445) 在「系统设置 → 隐私与安全性」中为此应用选择「仍要打开」。不要关闭系统全局安全保护。熟悉开发的使用者也可审阅源码后自行构建。
- GitHub 下载在国内可能不稳定；下载完成后的课程学习不需要联网。不包含在线 AI、账号同步、自动更新或自动评分。

## 可以做什么

| 功能 | 用法 |
|---|---|
| 学习总览 | 继续上次课程，查看已完成单元、计划天数、生词数量 |
| 84 天计划 | 按周查看当天材料、训练步骤和产出，手动打卡或撤销 |
| 阅读书房 | 24 篇短文，独立答题后展开参考答案，记录自己的理解 |
| 听力练习 | 12 段对话 MP3、12 个完整课程 MP4；音频倍速、后退 5 秒、整段循环、位置续播 |
| 口语与衔接 | 12 张口语卡、U00 资料指南、U01 证据改写、U02 八周课程、U03 四项工作坊和阶段检查 |
| 生词本 | 选中文本收藏，手动添加、编辑释义和例句、标记复习 |
| 笔记与进度 | 输入后自动保存，课程完成状态可撤销 |
| 导出与恢复 | 将所有学习记录导出为 JSON，可在升级或换电脑时恢复 |

0.2.10版共126个条目，其中102个训练条目和24个听力文字预览。预览阅读状态单独记录，完整听力音频待补，84 天任务沿用原编号。音频是对话片段，视频是完整教学课；文本对应对话音频，并非完整视频字幕。循环功能作用于整段音频，首版没有逐句时间轴、AB 区间循环、口语录音或发音评分。

建议第一天：打开 R01，读文章并回答问题；进入 L01，先听再展开文本；写三句自己的英文；完成当天计划。不要提前查看阶段检查答案。

## 学习记录与隐私

桌面版将记录保存在本机用户目录 `~/Library/Application Support/StepwiseEnglish/progress.json`，不会上传到 GitHub。应用文件和个人记录分开，替换应用版本不会主动清空记录。定期打开「设置与备份 → 导出学习备份」，将 JSON 放在自己的安全位置；备份含个人笔记，不要提交到公开仓库。

「恢复学习备份」会替换当前记录，导入前会提醒备份。格式不正确的备份不会替换已有记录；读取异常时停止写入，避免覆盖原文件。关闭应用后仍保留学习进度。没有跨设备实时同步。

网页源码 `index.html` 也可以用于开发预览，记录使用浏览器 localStorage；路径或浏览器改变时记录可能不同。正式离线使用请选择完整桌面包。原有课程资料包仍以根目录 `offline.html` 为入口。

## 构建与验证

在 macOS 上安装 Apple Command Line Tools，并提供 Python 3。客户端不需要 npm 包或远程依赖。

```sh
python3 scripts/build_macos_client.py /tmp/stepwise-client
node --test tests/client-state.test.cjs
codesign --verify --deep --strict /tmp/stepwise-client/拾阶英语.app
```

构建会重建离线页面和 `client/data.js`，编译 Swift AppKit/WKWebView 外壳，复制本地课程与媒体，生成图标并本地签名。Node 只用于开发测试，不是应用运行依赖。不要将构建输出放在仓库内。

课程源文件在原有 `lessons/`、`plans/`，不直接修改生成的 `client/data.js`。`scripts/build_offline.py` 会同步生成客户端课程数据；发布新版应用还需重新运行 Mac 构建与打包。个人记录按课程编号关联，维护时请保留编号。
